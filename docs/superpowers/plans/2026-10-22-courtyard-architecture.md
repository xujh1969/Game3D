# 庭院建筑实施计划

**目标：** 将既有12×8m三开间构图制作成可运行的首版建筑，保持三线索与双门通关。

**依据：** MASTER_PLAN.md、COURTYARD_COMPOSITION_DRAFT_v001.md及两张ENV v002概念。用户在审核材料提交后回复“继续开发”，按沿用方向推进记录，不表述为最终资产验收。

**架构：** Blender脚本生成柱梁、真实曲面灰瓦、窗墙、石台基和石径，输出GLB；Godot独立Architecture美术层和对应简化碰撞。复用木门，不把门静态烘入建筑。台阶使用与台基连续的斜坡碰撞，保留可见踏步，不增加角色跨阶系统。

**约束：** Godot4.7.2 Mobile、720p、30×30m、宋风创作、TEMP角色不冒充正式角色；保留v001草案及门v003。当前分支/工作目录按用户项目既有方式增量同步，不切换或重置。
