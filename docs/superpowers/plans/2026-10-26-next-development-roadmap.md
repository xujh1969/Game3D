# 山中古院下一阶段开发路线

日期：2026-10-26。状态：第一阶段开发包已交付；原生包真人完整流程仍待体验，后续阶段未开始。

**Goal:** 将现有30×30m庭院推进为可独立运行、动作自然、画面统一的5–10分钟探索解谜样板。

**Architecture:** 沿用现有角色控制、相机、三线索和双门流程，分阶段完善表现与交付。先建立可体验的Windows开发包，每阶段保留源文件和可回退版本。

**Tech Stack:** Godot4.7.2 / GDScript / Blender / Windows / Git LFS。

## 全局约束

- 保持第三人称青岚、写实宋风、30×30m庭院；本轮不扩展100×100m地图。
- 当前为三维技术实验；不恢复版权、来源或商用许可材料提交/审核门槛。
- 用户模型与Idle/Walking/Fast Run已经接入，不重复请求。
- Radeon集显/16GB，目标720p优先30fps；短时静止基线不能替代完整路线与稳定性验收。
- 本文为阶段路线，不是逐行代码方案；各阶段实现前根据当时问题补充具体修改范围。
