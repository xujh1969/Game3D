# MountainCourtyard

山中古院是一款面向 Windows 的单人第三人称宋风山居探索解谜原型，使用 Godot 4.7.2。

## 当前状态

工程处于 M0/M1 开发中。当前主场景是 30×30 米庭院灰盒，角色是明确标注的青岚 TEMP 代理；正式美术素材尚未提交。开发与验证状态见 `reports/MILESTONE_STATUS.md`，外部参考图和模型任务见 `handoff/REQUESTS.md`；项目管理 CSV 位于 `project_admin/`。

## 启动

使用 Godot 4.7.2 stable 导入项目并运行 `scenes/world/Courtyard_Blockout.tscn`。默认键位：WASD 移动，Shift 奔跑，鼠标转相机，E 互动，Esc 暂停/释放鼠标（功能仍在开发）。

## 验证范围

headless 导入/启动仅用于资源和脚本加载检查，不代表图形运行、可玩通关、GPU 性能或发布包通过。未测项目会在状态报告中如实标注。
